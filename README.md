# Conversor de modelos e de texturas de SotC

Script criado a fim de automatizar a conversão dos arquivos presentes no contêiner ~~NICO.DAT~~.

# Uso

Digite filename do script sem passar quaisquer argumentos, e será exibido uma pequena ajuda.

Além disso, deixe os arquivo no diretório "Wisi tools" no mesmo nível do script.

# Créditos

Créditos ao Wisi pelos executáveis ".exe"
